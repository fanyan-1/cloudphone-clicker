## 编译踩坑（重要）
1. `AccessibilityService.onBind(Intent)` 是 final，不能 override → 改为 startService/stopService + 静态回调 + sendBroadcast(ACTION_STATUS) 广播，Activity 用 BroadcastReceiver 收状态。
2. `catch (InterruptedException)` 若 try 内无抛该异常（sleep 已内部 catch）会编译报错 "exception never thrown" → 移除 loop 里多余的 catch。
- 两次编译失败均由 GitHub Actions 真实编译暴露，静态校验抓不到 → 以后安卓项目必须云端真编译验证。

## 追加：键盘按键功能（15:35）
- 用户反馈复刻版没有键盘按键功能（只有坐标动作），要求发真实 KeyEvent（W/A/S/D/F1等）。
- 技术现实：标准安卓无 root 无法向其他 App 注入 KeyEvent（INJECT_EVENTS 需系统签名）。云手机多数自带 root → 做多方案自动降级。
- 新增 KeyInjector.java：① 反射 InputManager.injectInputEvent（系统注入，无需 root）② Root Shell `su -c "input keyevent KEYCODE_xxx"`。自动 detect() 并在 App 顶部显示引擎状态，不可用时提前提示。
- ClickConfig 新增 ACT_KEY=3 + keyName/keyCtrl/keyAlt/keyShift 字段，JSON 持久化。
- ClickerService：dispatchOne 走 fireKey；同时模式把组内所有按键码合并成一次 send(arr,hold,true) 实现真组合键。
- MainActivity：动作类型下拉加「键盘按键(Key)」+ 按键名下拉（63键）+ Ctrl/Alt/Shift；显示 KeyInjector.statusText/detailText；有按键动作但引擎不可用时禁止启动并提示。
- 编译踩坑：ClickerService `long hold = Math.max(...)` 传给 int 参数 → 编译报错 lossy conversion，改 int hold。已加入校验断言。
- 校验：verify_project.py 全量 95/95、故障注入 18/18；GitHub Actions 编译 success（run 45776299129）；新 APK 32025 bytes 已覆盖本地。
